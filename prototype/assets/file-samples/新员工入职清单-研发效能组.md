# 新员工入职清单｜研发效能组

适用对象：入职第一周的新员工

负责人：新员工本人
协助人：直属主管、入职伙伴、HR

## 第一天

- [x] 领取办公电脑与门禁卡
- [x] 登录 eHR 并补齐紧急联系人
- [ ] 提交 GitLab 权限申请
- [ ] 提交研发环境权限申请
- [ ] 参加团队见面会并完成自我介绍

## 第一周

- [ ] 完成信息安全与数据合规学习
- [ ] 验证 GitLab、研发环境与团队知识库均可访问
- [ ] 与直属主管确认试用期目标
- [ ] 与入职伙伴完成第一次工作流程演练
- [ ] 记录仍未解决的问题和对应联系人

## 权限申请建议

| 权限 | 申请入口 | 完成标准 |
| --- | --- | --- |
| GitLab | IT 服务台 | 可以登录并访问所属项目 |
| 研发环境 | IT 服务台 | 可以完成环境登录验证 |
| 团队知识库 | 企业知识库 | 可以打开团队空间 |

## 需要帮助时

1. 账号或设备问题：在 IT 服务台提交工单。
2. 岗位目标与任务问题：联系直属主管。
3. 团队流程问题：联系入职伙伴。
4. 劳动关系或个人资料问题：联系 HR。

> 请勿在聊天、工单描述或共享文档中填写身份证号、银行卡号等敏感个人信息。
