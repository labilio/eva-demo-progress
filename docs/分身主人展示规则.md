# 分身主人展示规则

2026-09-08 用户确认：保留单张圆形 AI 头像，按场景补充主人文字。

| 入口 | 展示 |
| --- | --- |
| 分身会话标题、消息发送者 | 分身名、公共 AI 标、同行的次级灰色 `@主人姓名` |
| 添加成员、提及候选 | 第一行分身名与 AI 标，第二行 `@主人姓名` |
| 身份资料 | 标题下方显示可点击的「主人：姓名」，可查看主人并返回分身 |
| 紧凑会话列表、头像网格、已选标签 | 不重复主人，通过资料卡查看 |
| 通讯录及更多分身 | 保留主人与分身的分组关系，不再逐项重复主人 |
| 输入提示、正文提及、引用摘要、session 名 | 不追加主人 |

主人由 `EvaContactIdentities.resolve` 按稳定身份 ID 解析，通过 `EvaAIIdentity.ownerLabel` 渲染；不改变分身名称、会话内容或权限。个人助理、数字员工、项目管理专员和缺少真实归属的身份不显示个人主人。

标题和署名中的归属文字只展示，不触发 @ 消息，也不提供独立导航；资料卡的主人入口沿用已有身份卡往返能力。通讯录搜索主人姓名可找到他及其分身，搜索分身名可找到所属行；没有新增全局搜索类别或组合关键词语法。

长名称保持一行，保留 AI 标及至少 3em 的归属文字空间；完整主人通过原生悬停提示查看。候选采用固定两行结构，不以容器剩余宽度临时换行。

本地验收：Microsoft Edge 1200×800、100% 缩放；标题、超长名称、资料卡主人往返、选人候选、提及不携带主人、搜索主人／分身、草稿保留及跨入口切换通过。个人 Eva、消息中栏、我的 AI 团队中栏的基准布局文件未修改。截图和浏览器脚本位于本地忽略目录 `artifacts/clone-owner/`；Preview 部署与目标 commit 的证据记录在 PR。

通讯录补充（现行）：真人作为父级，分身在其下缩进并按宽度换行。1～6 个全部展示，超过 6 个在原组内展开／收起；搜索直接显示匹配分身。此整体设计取代先前并列列头、短竖线和固定前两个加更多弹窗的方案，详见《通讯录身份卡验收》。
