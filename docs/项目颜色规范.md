# 项目颜色

项目的 `colorKey` 是颜色唯一数据源，用户不选择颜色。新项目按稳定 ID 分配有限色板；改名、排序及刷新不改变配色，允许不同项目复用颜色。四个预置项目保留原有颜色。旧数据通过公共适配器迁移，保存时只保留 colorKey，不持久化派生色值。

`prototype/004-project-appearance.js` 的 `EvaProjectAppearance` 管理全部项目配色：`normalize` 生成存储数据，`view` 为现有组件派生兼容字段，`get` 返回 accent/surface/border，`css` 返回随 color-scheme 变化的 CSS 颜色。light/dark 使用同一色板映射。既有历史种子迁移脚本保留历史色值用于旧版兼容，不作为当前显示色板。

项目目录、关注分类图标、最近/搜索项目路径图标和聊天顶部项目图标共用此接口。默认群头像由成员仓库解析群/子区所属项目，实时取色；群不保存项目颜色副本。自定义群头像优先，非项目群继续采用稳定独立颜色，人类和 AI 身份头像不变。

公共头像支持 theme 参数，并默认读取客户端 color-scheme。当前任务不增加深色模式开关；后续主题实现须在主题变化后触发组件正常重渲染，并统一设置 color-scheme。

新入口不得按项目名字猜颜色或手写项目色值。项目名称与图标共同表达归属，颜色不能代替名称或用于判断权限。
