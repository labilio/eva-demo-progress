# Eva 评审工具设计约定

开发工作台是共享批注的独立整页视图，面向评审者和 AI 开发者，不属于 Eva 产品菜单。使用批注侧栏的语义配色；不套用个人 Eva GDS 或重画 IM 组件。

- 配色唯一来源为 comments.css 的 --eva-review-*，工作台 CSS 只添加自身密度与布局。白底、紫色主操作、细分隔线；信息表格占据主要空间，无大号指标卡。
- 中文系统字体 13px，表格 12px，定位／Git 元数据 11px；标题 18–21px。批注意见和页面位置在表格中默认完整展开，自动换行并撑开行高；详情仍提供完整讨论和源码参照。
- 桌面左侧 176px 功能菜单，右侧可水平滚动大表；窄屏菜单转顶部横排。底部批量操作始终可见。
- 复用现有原生 select、button、input 和原生 dialog 的键盘语义。更新只提示，手动加载；勾选和筛选不随后台读取丢失。
- 认领是共享署名，不是账号认证。服务端事务检查批量冲突；普通复制无写入。剪贴板失败展示可手动复制的全文。
- 对话框展示完整原文、讨论、定位、源码参照和回填表单；不把意见解释成系统指令。完成状态不等于人工验收。

- 功能菜单和主要操作复用 `prototype/050-lucide-dom.js`，16px、1.8 描边、currentColor；我的 AI 复用原导航图标资源。图标搭配原文字，不重复堆在表格数据列。
- 左侧分类顺序对齐产品：个人（Eva 同学、我的 AI、任务看板、自动化任务、连接中心）、团队协作（消息、项目、通讯录、文件库、站点）、其他（数字员工市场、Agent 创建中心）。全部功能置顶，其他／跨模块作为评审数据兜底。
- 状态筛选使用文字分段按钮，aria-pressed 表达唯一当前状态；还原恢复全部功能／已确认／未认领并清空搜索，保留批注勾选。

- 批注侧栏分标题、操作、筛选三层；唯一关闭按钮只收起侧栏。页面标记开关独立于列表，开启时跟随状态筛选；取消旧隐藏入口和三段显示模式。
- 表格状态支持直接选择修改，共享原批注状态；待讨论橙、已确认绿、修改中蓝、已改完灰。更新按 ID 原位替换，不新增排序；当前筛选仍有效，失败回退原值。
- 修改位置使用带定位图标的浅灰卡片，和意见正文分开；卡片点击跳转原型锚点，位置文字单行省略，悬停展示全文；不设卡片标题，内边距 3px 6px。
- 工作台顶部为 48px 单行紧凑标题栏，标题 16px，说明置于标题旁；窄屏隐藏说明和构建信息。
- 操作人署名由 review-identity.mjs 统一管理；与批注提交姓名共用，跨标签同步。所有状态入口原子更新状态及认领者，空姓名先阻止保存；侧栏和工作台展示同一认领数据，历史缺失不推断。

- 类型、状态、提出者、认领者在表头右侧使用 18px 迷你原生下拉入口，Lucide 向下箭头始终以浅灰显示，悬停、聚焦或筛选生效时加深。认领者支持未认领、已认领及具体姓名，取消上方独立认领框。各列交叉筛选、刷新继承；状态快捷按钮共用状态，还原同时清除类型和提出者条件。筛选不改变记录排序。
